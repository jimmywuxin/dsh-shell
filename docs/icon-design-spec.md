# dsh App 图标设计方案 v2

> 适用：`~/Applications/dsh.app`（原生 WKWebView 壳）
> 当前采用：**黑色变体 A**（黑鲸 + 浅瓷底，2026-10-19 定）
> 母版：`assets/icon-black-1024.png` ｜ 蓝版母版：`assets/icon_1024.png` ｜ 生成器：`assets/icon-src/gen_icon.py` ｜ 展示图：`assets/icon-black-preview.png`
> 生效：`bash build.sh`（`sips` → `iconutil` → 写入 `Contents/Resources/AppIcon.icns`）

---

## 1. 为什么要重做

v1 图标（`assets/icon_1024_v1.png`）不是"不好看"，是不合 macOS 规范：

| v1 问题 | 后果 | v2 处理 |
|---|---|---|
| 图形铺满 1024 画布，无安全边距 | Dock 里比系统图标大一圈，像贴纸 | 收进 824×824 主体，留 100 px 边距 |
| 圆角为普通圆角矩形，非连续曲率 | 放大后转角"发硬" | 超椭圆（n=5）连续曲率容器 |
| 纯平色 `#4D6BFE`，无层级 | 128 px 以下略显平、缺乏重量 | 渐变 + 内阴影 + 轮廓光 + 落地阴影四层 |
| 无规范尺寸清单 | 小尺寸靠缩图，细节糊 | 走标准 `.iconset` 10 槽位 |

## 2. 品牌延续（不可动的部分）

换图标后必须仍然"一眼是 dsh"，因此以下三项**零改动**：

1. **鲸鱼剪影**——直接从 v1 图标提取 alpha 遮罩（`assets/icon-src/whale_crop.png`），轮廓、眼睛负形、腹线一字未重绘。
2. **蓝色主色相**——v1 实测主色 `#4D6BFE`（H≈226°），v2 主色 `#4C61F2`（H≈228°），同色相族内微调，不跨色。
3. **白鲸 / 蓝底的正负形关系**——白图形 + 蓝底，不反色、不加第二图形。

## 3. 设计风格

**macOS Big Sur 之后的单层图标语言：几何、克制、靠光影做层次。**

- 不拟物（不做塑料、金属、玻璃拟态）
- 不玻璃化（不做毛玻璃、半透明叠层）
- 不加文字、不加描边、不加外发光特效
- 体积感只靠三样：**方向性渐变**（顶光）、**内阴影**（贴地）、**极淡轮廓光**（分离主体）

## 4. 配色方案

| 色值 | 角色 | 面积占比 | 说明 |
|---|---|---|---|
| `#7E97FF` | 顶部高光 | ≈18% | 渐变起点，模拟顶光入射 |
| `#4C61F2` | 品牌主色 | ≈45% | 与 v1 同色相，作为视觉锚点 |
| `#232F8C` | 底部深色 | ≈37% | 渐变终点；**不从纯黑起**，深色桌面下不糊进背景 |
| `#FFFFFF` → `#EDF1FF` | 鲸鱼主体 | ≈17% | 轻微纵向渐变，底部略冷，避免"死白" |
| `#A8E9FF` | 冷边光 | 描边层 | 24% 不透明度、7 px 模糊，只做上下分离 |
| `#0A1233` | 内阴影 | 底部 32% | 只压下半部，让容器有厚度 |

- 渐变方向：左上 → 右下（`x1=.12 y1=0 → x2=.88 y2=1`），角度约 130°。
- 对比度实测：白鲸 vs 主色区 **4.88:1**、vs 深色区 **11.3:1**；顶部高光区仅 **2.71:1**，所以鲸鱼**不进入顶部高光带**，用轮廓光与投影补足边界。

## 5. 视觉元素与构图

```
层级（从下到上）
① 落地阴影    #080C28 / 17% / 模糊 26 / 下移 6   → 给容器"重量"
② 渐变容器    超椭圆 824×824                    → 平台识别
③ 内阴影 + 内高光 stroke 3 / 白 16%             → 厚度
④ 鲸鱼        512×384（占主体宽 62%）            → 品牌
   └ 冷边光（位移 -4,-5）+ 投影（dy 9 / 18%）    → 与底分离
```

- **画布**：1024×1024，透明背景。
- **容器**：824×824，居中，四边各 100 px（9.77%）安全边距；超椭圆指数 n=5，等效转角半径 ≈185 px。
- **鲸鱼盒**：`x=254, y=308, w=512, h=384`，几何中心 (510, 500)——比画布中心上移 12 px，抵消尾部上翘造成的视觉重心偏移。
- **占比**：鲸鱼宽度 = 主体的 62%，与 v1（61.7%）一致，视觉重量不变。
- **留白**：鲸鱼四周距容器边 ≥60 px，任何尺寸下不与容器边缘相切。

## 6. 整体调性

**深海 · 克制 · 工具感。**

它是"把 Web GUI 装进桌面的壳"，不是消费级娱乐应用：不需要吉祥物表情、不需要高饱和撞色、不需要动效暗示。要的是在 Dock 一排图标里安静、被认出、不抢戏。

反面清单（评审时用来否决改稿）：加文字 ｜ 加描边 ｜ 改拟物 ｜ 加多色 ｜ 鲸鱼换姿势 ｜ 底色调纯黑 ｜ 换掉蓝。

## 7. 尺寸规格与平台规范

### 7.1 macOS `.iconset`（构建实际产出）

| 槽位文件 | 像素 | 主要场景 |
|---|---|---|
| `icon_16x16.png` | 16 | Finder 列表、菜单栏下拉 |
| `icon_16x16@2x.png` | 32 | Retina Finder 列表 |
| `icon_32x32.png` | 32 | Finder 图标视图（小） |
| `icon_32x32@2x.png` | 64 | Retina 图标视图、⌘Tab |
| `icon_128x128.png` | 128 | Dock（默认档）、Launchpad |
| `icon_128x128@2x.png` | 256 | Retina Dock、Launchpad |
| `icon_256x256.png` | 256 | Finder 预览、关于窗口 |
| `icon_256x256@2x.png` | 512 | Retina 预览 |
| `icon_512x512.png` | 512 | 大图标视图 |
| `icon_512x512@2x.png` | 1024 | 商店/宣传、Retina 大图标 |

### 7.2 平台规范要点

- **容器规范**：1024 画布 + 824 主体 + 100 边距 + 连续圆角，是 macOS 11+ 的统一网格。满画布图标会在 Dock 中系统性偏大，这是 v1 最明显的问题。
- **单一资产即可**：浅色/深色桌面共用同一图标，macOS 不做自动反转；因此底线收在 `#232F8C`，深色底不糊。已用 128/64/32/16 px 实测（见展示图下半区）。
- **macOS 26 着色图标**：系统可对图标做 tinted 处理。当前为单层资产，系统自动着色即可用；若后续要做精细着色变体，用 `assets/icon-monochrome.png`（纯黑轮廓 + alpha）作为模板层，在 Icon Composer 里重建为「底 / 鲸鱼 / 高光」三层。
- **菜单栏**：本 app 无常驻菜单栏图标；如将来需要，使用 `icon-monochrome.png`（template image，系统自动跟随明暗与强调色）。
- **App Store**：不适用（本地自用 app，未走商店）。若将来上传，需另出**不带透明边、不带落地阴影**的不透明 1024 方形图——两者的取舍不同，不要直接复用本资产。
- **其他平台**：本项目仅 macOS。若将来移植，1024/512/256/128/64/32/16 的 PNG 集可直接用于 Linux `.desktop`、Web favicon（32/180）；Android 需按 adaptive icon 拆前后景（前景用鲸鱼、背景用 `#4C61F2` 纯色）。

### 7.3 小尺寸光学校正（可选）

标准母版在 16 px 下鲸鱼细节（尾鳍、腹线）会合并成白色块，这是单母版方案的固有代价。若以后觉得 16/32 槽位不够锐：

- 只在 `icon_16x16*` / `icon_32x32*` 四个槽位使用**放大 6% 的鲸鱼 + 去掉轮廓光**的变体，主母版不动；
- 属于尺寸微调，不改设计语言，可在 `build.sh` 的 iconset 段落里加两条 `sips` 分支实现。

## 9. 构建接入

`build.sh` 第 111–126 行已按标准流程处理，**不需要改代码**：

```
$ICON_SRC                     # build.sh 第 114 行，当前 = assets/icon-black-1024.png
  └ sips 缩放到 16/32/64/128/256/512/1024
     └ 复制出 @2x 槽位
        └ iconutil -c icns → build/AppIcon.icns
           └ 拷入 dsh.app/Contents/Resources/AppIcon.icns
```

换图只需改 `build.sh` 的 `ICON_SRC` 指向对应母版后跑 `bash build.sh`（蓝版：`assets/icon_1024.png`）；改设计参数则改 `gen_icon.py` 的调色板常量再重跑。

## 11. 黑色变体（同几何 · 只换配色）

两套黑色方案与蓝版**共用全部几何常量**：1024 画布、824 主体、100 边距、超椭圆 n=5、鲸鱼 512×384（占主体 62%，落位 `x254 y308`）。差异只有调色板，因此线宽、轮廓、比例、负形细节天然一致——这是"风格一致"的硬保证，不靠肉眼对。

| | A · 黑鲸 + 浅瓷底（**已采用**） | B · 白鲸 + 黑底（反相，备选） |
|---|---|---|
| 适用 | 浅色桌面、文档/网页里的图标位 | 深色桌面、强调黑、需要"墨块"存在感 |
| 鲸鱼 | `#0C0E13 → #1A1E26` | `#FFFFFF → #EFF2F8` |
| 容器 | `#FFFFFF → #F4F6FA → #DCE2ED` | `#23262D → #11141A → #000000` |
| 内阴影 | `#2A3550` 10% | `#000000` 42% |
| 轮廓光 | 关（黑鲸压白底，加暗边会显脏） | `#FFFFFF` 10%（白鲸在黑底靠它收边） |
| 鲸鱼投影 | 关（黑对白不需要再加投影） | 关 |
| 细边 | `#0B1220` 10% / 3 px | `#FFFFFF` 12% / 3 px |
| 落地阴影 | `#0B1220` 14% | `#000000` 26% |

**单色纪律**：黑色变体里只出现黑、白两级（外加容器上的低透明度黑/白），不掺品牌蓝、不做灰彩过渡。鲸鱼与容器实测对比度：A 顶部 **19.3:1** / 底部 **14.8:1**，B 顶部 **15.1:1** / 底部 **21.0:1**，全区间远高于图标的 3:1 可用线。

**纯黑 mark**（`icon-black-mark-1024.png`）：透明底、鲸鱼与图标内同位同尺寸，可直接当 logo / 水印 / 文档页眉标识；深色背景用反白版。它等同参考图里"黑鲸 + 白底"的用法，但轮廓、眼睛、腹线与 App 图标完全同源。

**换用方式**（三种，不影响现有蓝版）：

```bash
# 1) 只想看：把 icns 拷进某份 app 副本，不动线上
cp assets/AppIcon-black.icns /path/to/dsh-copy.app/Contents/Resources/AppIcon.icns

# 2) 正式把线上图标换成黑色变体（会重签，ad-hoc 足够）
cp assets/AppIcon-black.icns ~/Applications/dsh.app/Contents/Resources/AppIcon.icns
codesign --force --sign - ~/Applications/dsh.app
killall Dock

# 3) 让变体成为默认（A 已是默认）：改 build.sh 的 ICON_SRC 后 bash build.sh
```

**验收补充**：

- [ ] A 在纯白桌面上：容器边界靠渐变 + 10% 细边成立，不靠投影硬撑
- [ ] B 在纯黑桌面上：12% 白细边能勾出容器轮廓，不糊成一片
- [ ] 16 px：A 的白色容器在浅色背景上会"融"掉，只剩黑鲸——这是预期的（同 Apple Notes），不是缺陷
- [ ] 三变体并排，鲸鱼轮廓与负形细节必须逐像素同形
